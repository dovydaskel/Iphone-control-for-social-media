Opens TikTok → + → picks the (only) video in Photos → swaps the sound for the next one in your Favorites sounds (cycling back to the first) → types the description → Drafts or Post. With Instagram on, it then waits for TikTok's saved copy of the posted video (with the sound) to land in Photos and makes a reel of it with the same caption → Save draft or Share. Typing uses the on-screen keyboard: letters, numbers, common symbols, # and @ and new lines work; emoji and accented letters are skipped.

Schedule

––

    Runs on this Mac's clock, so the Mac must be awake (and this server running). The random delay makes it start at a slightly different time each day. A Send video step puts the routine's next queued video into Photos (phone on USB), so each run posts a different one; add the videos under the routine after saving it. An Upload step with an empty description uses the one in the TikTok / Instagram card. A routine stops at the first step that fails.

    Send to Photos

      One-time phone setup (USB Import)

      The iPhone must be plugged into this Mac; no internet needed.

      1. Install VLC from the App Store and open it once.
      2. With the phone plugged in, click
      3. On the phone open Shortcuts → +.
      4. Add Get Contents of Folder and pick On My iPhone › VLC › Mac Import.
      5. Add Save to Photo Album (Recents) for the folder contents. No delete step needed; the Mac clears the folder.
      6. Name it USB Import, then Share → Add to Home Screen.
      7. Run it once by hand and answer the permission prompts with Always Allow.
      One-time phone setup (Delete videos)

      Deletes every video in Photos (they go to Recently Deleted for 30 days). With iCloud Photos on, that's on all your devices.

      1. On the phone open Shortcuts → +.
      2. Add Find Photos → Add Filter → Media Type is Video. Leave Limit off.
      3. Add Delete Photos with the found Photos as input.
      4. Name it Delete Videos.
      5. On the home screen long-press → Edit → Add Widget → Shortcuts → the small single-shortcut widget → Add Widget. Tap the new widget and pick Delete Videos. Drag it to the right of the USB Import widget.
      6. Run it once by hand and answer any permission prompts with Always Allow. iOS still asks "Allow … to delete?" every run; the server taps Delete for you.
